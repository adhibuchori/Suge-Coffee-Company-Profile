# Tech Stack

- **Language**: TypeScript 5, strict
- **Styling**: Tailwind CSS v4
- **State**: Zustand (UI state only)
- **Package manager**: Bun
- **Linter**: oxlint (config: oxlint.json, ignore: .oxlintignore), max-lines: 150
- **Formatter**: oxfmt
- **Type checker**: tsc --noEmit
- **Test runner**: Vitest (config: vitest.config.ts, setup: src/testing/setup.ts)
- **Port**: 3010 (dev)
