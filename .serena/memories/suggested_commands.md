# Suggested Commands

All commands MUST use the `rtk` prefix (RTK token-killer proxy).

```bash
rtk bun dev           # start dev server on port 3010
rtk bun fl            # format (oxfmt) + lint (oxlint)
rtk bun type-check    # tsc --noEmit
rtk bun test          # vitest
rtk bun test:coverage # vitest --coverage
rtk bun run build     # production build
```
